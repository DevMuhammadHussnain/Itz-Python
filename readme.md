## About

**Itz-Python** is a personal collection of Python projects.

Instead of keeping individual experiments and applications in separate repositories, this repository acts as a central place for Python work ranging from small experiments to complete applications.

Projects may include:

- Command-line applications
- Terminal user interfaces
- Automation scripts
- Mathematical and computational experiments
- File-processing utilities
- Developer tools
- Experiments with Python libraries
- Learning projects
- Small applications
- Future Python projects

The repository will evolve continuously as new projects are created.

# Getting Started

Clone the repository:

```bash
git clone https://github.com/DevMuhammadHussnain/Itz-Python.git
```

Enter the repository:

```bash
cd Itz-Python
```

Projects may have different dependencies, so check the project's individual `README.md` before running it.

For projects using `requirements.txt`:

```bash
python3 -m venv .venv
```

Activate the environment on macOS/Linux:

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

Install the project's dependencies:

```bash
pip install -r requirements.txt
```

# Environment Variables

Projects that require environment variables should provide an example file:

```text
.env.example
```

For example:

```env
API_KEY=your_api_key_here
OUTPUT_DIR=./output
```

Actual `.env` files containing secrets should **never** be committed.
